# Прогулка героя внутри Бурдж Халифы

Одностраничная игра на чистом Canvas, где главный персонаж (использует изображение из `assets/hero.svg`) свободно бродит по смотровому уровню Бурдж Халифы с прозрачными стеклянными панелями.

## Запуск
1. Откройте `index.html` в современном браузере (Chrome, Edge, Firefox, Safari).
2. Управляйте перемещением стрелками или клавишами WASD.

## Кастомизация героя
Замените файл `assets/hero.svg` на свой PNG или SVG (рекомендуемый размер 96×128) с тем же именем — игра автоматически подхватит новый образ.
